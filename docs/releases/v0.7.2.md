Masaki 0.7.2

## Что нового

- **Перенос в поиск.** Перетащите выделенный текст, картинку со страницы или файл изображения в боковую панель либо док — откроется палитра с готовым запросом. Картинки, включая WebP, можно отправить в AI Mode через Google Lens. Результат открывается в новой вкладке.
- **Панель сразу прозрачная.** При раскрытии больше нет серой подложки на первые полсекунды; стекло сохраняется на протяжении всей анимации.
- **Автозаполнение не мешает входу.** После подстановки логина и пароля список больше не раскрывается повторно и не перехватывает клик по «Войти». Явный щелчок по полю позволяет выбрать другой аккаунт.
- **Переходы в приложения.** Ссылки Telegram и других приложений обрабатываются при обычном клике, переходе через новое окно и HTTP-редиректе. Masaki спрашивает подтверждение, затем передаёт ссылку системе; пустая вкладка не остаётся.
- **Вход Google.** Устранено несогласованное определение браузера в первом документе входа из меню аккаунтов и во всплывающих окнах. Форма входа больше не перезагружается, ответ возвращается исходному сайту.
- **Ключи доступа.** Предложения passkey обновляются, даже если сайт начал запрос уже после фокуса в поле. Отмена запроса убирает список. Собственные ключи Masaki больше не сообщают о неподдерживаемом входе с телефона.
- **Обзор совместимости с Chrome.** В репозитории появился [список реализованных возможностей и оставшихся ограничений](https://github.com/GXUser7/Masaki/blob/v0.7.2/docs/CHROME-COMPATIBILITY.md).
- **Сборка Mac.** Workflow переведён на поддерживаемый macos-15 после отключения macos-14 в GitHub Actions. Версия 0.7.1 не была опубликована из-за недоступного runner; этот выпуск включает все её изменения.

Проверены автозаполнение, подписи ES256/RS256, перенос и отправка изображений в подставной Lens, первые кадры панели, а также запуск упакованной Windows-сборки. Вход Google проверен на подставном сервисе; реальная авторизация в этом прогоне не проверялась. Передача ссылок в приложения проверялась на границе API системы без запуска пользовательских программ.

Установщик Windows не подписан — SmartScreen может показать предупреждение (подробности в README).
